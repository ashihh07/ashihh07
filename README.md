### 🔐 SSH Auth Monitor

**Real-time SSH authentication monitoring and brute-force detection.**

[View Repository →](https://github.com/ashihh07/ssh-auth-monitor)

**What it does:**

- Monitors SSH authentication logs in real time
- Detects repeated failed login attempts
- Identifies potential brute-force activity
- Tracks suspicious source IP addresses
- Generates CSV-based security alerts

**Built with:** `Python` `Linux` `Log Analysis`

### 🌐 Network Connection Watcher

**A lightweight network monitoring tool for identifying potentially suspicious connections.**

[View Repository →](https://github.com/ashihh07/network-connection-watcher)

**What it does:**

- Monitors active network connections
- Flags connections involving suspicious ports
- Looks for patterns that may indicate beaconing
- Records detected events
- Exports alerts for further analysis

**Built with:** `Python` `Networking` `Linux`
